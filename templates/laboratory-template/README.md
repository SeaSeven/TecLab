# Plantilla de laboratori

Copia labs/lab-002 com a esquelet i assigna un identificador nou a metadata.json i al hash inicial d’index.html. Crea lab.js i lab.css per a la vista específica; separa els càlculs de la interfície. Registra la vista a shared/components/app.js. El LAB-001 és l’exemple complet.

Executa npm run build per actualitzar el catàleg. Inclou Fonaments i Ajuda i comprova la navegació de retorn al portal.
